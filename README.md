# 🎬 MovieLens Analysis & Movie Ranking System

This project analyzes the MovieLens dataset to rank movies based on user ratings, popularity, and audience engagement. The project combines data analysis, statistical ranking techniques, and recommendation system concepts to identify highly rated and popular movies.

## 📌 Project Overview

Movie recommendation and ranking systems are widely used by streaming platforms to improve user experience. In this project, movie ratings from users were analyzed to:

- Identify top-rated movies
- Analyze user rating behavior
- Rank movies based on rating statistics
- Explore popularity trends
- Build a movie ranking system

The project focuses on data analysis and ranking methodologies using user-generated ratings.

---

# 📊 Dataset Information

The MovieLens dataset contains:

- User IDs
- Movie IDs
- Movie titles
- Genres
- User ratings
- Timestamps

The dataset includes thousands of movies and user ratings collected from real users.

# 🔍 Project Workflow

## 1. Data Loading & Exploration

The dataset was explored to understand:

- Dataset size
- Missing values
- Rating distributions
- Most rated movies
- User activity levels

---

## 2. Data Cleaning

The preprocessing steps included:

- Removing duplicates
- Handling missing values
- Formatting movie information
- Merging datasets when necessary

---

## 3. Exploratory Data Analysis (EDA)

Several analyses were performed, including:

- Distribution of movie ratings
- Most popular movies
- Highest-rated movies
- User rating frequency
- Genre analysis

Visualizations were created to better understand audience behavior and movie popularity.

---

## 4. Movie Ranking System

Movies were ranked using:

- Average user ratings
- Number of ratings
- Popularity metrics
- Statistical filtering

This helps avoid ranking movies highly based on only a few ratings.

---

# 📈 Key Insights

- Popular movies tend to receive more consistent ratings.
- Some movies achieve high average ratings but with low rating counts.
- Rating count is important when evaluating movie quality.
- User behavior strongly affects ranking systems.
